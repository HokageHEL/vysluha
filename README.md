# Вислуга 360

Автономний застосунок: послужний список, розрахунок вислуги і експорт витягу
у Word / Excel. Без бекенда і без бази даних — усе рахується в браузері,
дані нікуди не надсилаються.

Назва — від «пенсійної» арифметики, на якій усе тримається: 1 рік = 360 днів.

Витягнуто з проєкту `human_data_center` (вкладки «Послужний список» і «Вислуга»).

## Що вміє

- **Послужний список** — один екран: ліворуч періоди служби (терміни, посада,
  місце), праворуч живий передперегляд витягу 1в1 як друкований. Окремого
  режиму редагування немає.
- **Записи про контракт** — призов по мобілізації, укладення та продовження
  контракту вставляються прямо в проміжок між періодами; у витягу вони стають
  рядком на всю ширину таблиці, а місце визначає дата. Є шаблони з
  підстановкою дати прописом.
- **Підпис** — посада, звання і прізвище підписанта плюс виконавець. Незаповнені
  поля друкуються підказкою в дужках, щоб їх не проґавили перед друком.
- **Вислуга** — календарна вислуга з періодів послужного списку плюс додаткові
  періоди з коефіцієнтами: пільгова ×3, навчання ×0,5, не зараховується ×0.
  На перетинах день рахується за більшим коефіцієнтом; ×0 виключає день повністю.
  Навчання зараховується не більше 5 років (п.2 Постанови КМУ № 393).
- **Експорт** — `ВИТЯГ З ПОСЛУЖНОГО СПИСКУ` у .docx за зразком витягу: A4,
  поля 2/3/2/1 см, Times New Roman 14 пт, таблиця з трьох колонок («Терміни
  проходження служби», «Займана посада», «Місце проходження служби») і чорними
  рамками 0,5 пт. Те саме — у .xlsx.
- **Родовий відмінок** — шапка витягу вимагає «майора ІВАНЕНКА Івана
  Івановича». Звання відмінюються за правилом і точні для всього довідника;
  ПІБ — евристика, тож згенерований рядок показується в редагованому полі й
  ручна правка завжди має пріоритет.
- **Збереження** — автозбереження в `localStorage` браузера + експорт/імпорт
  усього стану у файл, щоб перенести на інший пристрій.
- **Логотип** — `public/favicon.svg`, той самий знак у шапці (`Logo.tsx`).
  Тільки SVG: у системі не було чим згенерувати PNG-фолбек, тож іконки не
  буде в Safari < 14 та на іконці «на екран Home» в iOS.
- **Тема** — світла / темна, за замовчуванням береться системна, вибір
  запам'ятовується. Палітра свідомо без абсолютно білого й абсолютно чорного.
- **Інструкція** — модалка «Як користуватись» пояснює порядок дій: спочатку
  дані військовослужбовця, далі послужний список, і лише потім особливі
  періоди. Показується автоматично при першому відкритті, далі позначається
  прочитаною в `localStorage`; повторно відкривається кнопкою в шапці.

Дати рахуються в «пенсійному» форматі: 1 рік = 12 місяців = 360 днів,
1 місяць = 30 днів. Період враховується включно з першим і останнім днем.

## Локальний запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc + vite build -> dist/
```

## Деплой на Vercel

Репозиторій уже містить `vercel.json` (SPA-rewrite на `index.html`).

**Через веб-інтерфейс:**

1. Створити git-репозиторій і запушити на GitHub:
   ```bash
   git remote add origin git@github.com:<user>/vysluha.git
   git push -u origin main
   ```
2. На vercel.com → **Add New… → Project** → імпортувати цей репозиторій.
3. Налаштування визначаються автоматично (Framework: Vite, Build: `npm run build`,
   Output: `dist`). Root Directory лишити порожнім.
4. **Deploy**.

**Через CLI:**

```bash
npm i -g vercel
vercel          # прев'ю-деплой
vercel --prod   # продакшн
```

## Структура

```
src/
  App.tsx                       стан, вкладки, збереження/імпорт JSON
  components/
    HowTo.tsx                   покрокова інструкція для користувача
    PersonForm.tsx              ПІБ, звання, рік народження, РНОКПП, шапка
    SignatureForm.tsx           підвал витягу: підписант і виконавець
    RankSelect.tsx              вибір звання зі списку або введення вручну
    EditorRow.tsx               спільний рядок-картка для всіх списків
    EventTemplateMenu.tsx       меню заготовок для записів про контракт
    ServiceRecordTab.tsx        періоди й записи + передперегляд + експорт
    ServiceCalculatorTab.tsx    додаткові періоди + підсумок вислуги
  lib/
    service-calc.ts             посегментний розрахунок вислуги
    extract.ts                  модель витягу: шапка, рядки таблиці, підвал
    genitive.ts                 родовий відмінок звань і ПІБ
    eventTemplates.ts           заготовки записів про мобілізацію і контракти
    exportServiceRecord.ts      генерація .docx / .xlsx
    storage.ts                  localStorage + JSON
    theme.ts                    світла / темна тема
    ranks.ts                    військові звання за зростанням, 3 групи
    types.ts                    ServiceExtractPerson, ServiceRecord,
                                ServiceEvent, SignatureBlock
```
